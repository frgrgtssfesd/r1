# Путешественник во времени (Java 17+, без внешних библиотек)

Запуск: `run.sh` (Linux/macOS) или `run.bat` (Windows). Нужен установленный JDK 17+.

Управление: WASD / стрелки - ходьба, E - говорить с персонажем, 1-3 - выбор ответа, J - журнал решений.

Структура (src/timetravel):
- Main.java - окно
- GamePanel.java - игровой цикл, ввод, графика
- Player.java - здоровье, знания, ресурсы
- Npc.java - персонажи
- GameMap.java - карты 3 эпох, препятствия, порталы
- Story.java - 14 событий сюжета, 5 финалов
- ResultWriter.java - запись результата в results.txt


Цель: в каждой эпохе поговорить со всеми NPC, затем войти в портал. Итог зависит от показателей.
